Form Input Text

core/partials/atoms/form_input_text.html

Config-driven text input (text / email / tel / number / url / password / search). Supports a vertical layout (default, label above) and a row layout used by the intake form-shelf pattern. Includes status icon, error / help text, full a11y wiring (aria-describedby, aria-invalid, required + sr-only). Use this for any non-Django-form input — for Django BoundField-bound inputs, use form_field.html.
